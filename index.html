📌 Pin it Your Way
A smarter way to pin to Pinterest
(Browser Extension – Work in Progress)
This extension project is currently in active development.
Stay tuned for updates.

Expected Features

Built on the official Pinterest API for speed, reliability, and privacy.

  • One-click save Alpha

    Save from any website with a clean, fast UI that gets out of your way.

  • Instant board picker Coming soon

    Type-ahead search and recent boards to file pins exactly where they belong.

  • Multi-image selection Coming soon

    Select multiple images on a page and pin them in one go.

  • Custom descriptions & hashtags Coming soon

    Add titles, descriptions, and hashtags before you save.

  • Alt text support Coming soon

    Add accessible alt text to your pins as you save them.

  • Duplicate detection Coming soon

    Warns you when an image looks like something you’ve already pinned.

  • Bulk pinning queue Coming soon

    Queue pins and let them post in the background—even on flaky connections.

  • Keyboard shortcuts Coming soon

    Speed through repetitive tasks with configurable shortcuts.

  • Account switching Coming soon

    Quickly switch between personal and business Pinterest accounts.

  • Privacy-first

    No scraping. No tracking. Uses only the official Pinterest OAuth & API.
